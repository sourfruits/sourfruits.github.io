# Tag kinds — the one place to say what kind each tag is.
#
# Posts don't change: keep writing  tags: essay, film  as usual.
# The site looks each tag up here to build the filters and to order tags on
# posts and cards (form, then medium, then theme).
#
#   form:    what kind of post it is — one per post. blurb is a short take
#            (homepage only); everything else also goes on Writing, where the
#            forms are the tabs.
#   medium:  what it's about — film, books, music… (the tabs on the homepage)
#   Anything NOT listed below is a theme (philosophy, memory, cities…), so a
#   new theme needs no setup. A new form or medium gets added to its line.
#
# One kind per line, tags separated by commas, in the order the tabs should
# appear. Lines starting with # are notes.

form: blurb, essay, criticism, poem, reportage
medium: film, books, music
